# Lab 7 Capstone Project
## Project Overview
This project demonstrates Linux system administration and automation using Bash scripting.

## Scripts Included
### 1. monitor.sh
Displays system disk usage and filesystem information.
### 2. backup.sh
Creates compressed backups of selected project files using the tar command.
### 3. log_analyzer.sh
Analyzes log files, counts total lines and identifies ERROR and WARNING messages.
### 4. dashboard.sh
Displays system date, time, uptime, disk usage, memory usage and logged-in users.
